# **App Name**: Edumate

## Core Features:

- Login Page: Create a simple login page that accepts a username.
- Admin Page: Generate a basic admin page after successful login.
- Route Protection: Protect the admin route so that it is only accessible to authenticated users.

## Style Guidelines:

- Primary color: Soft blue (#7BBEEF) to convey trust and serenity.
- Background color: Light grayish-blue (#E8F4FC), a desaturated shade of the primary, for a calm atmosphere.
- Accent color: Muted teal (#45A29E) for interactive elements; this analogous color adds subtle contrast without being jarring.
- Font choice: 'PT Sans' (sans-serif) for both headlines and body text, to create a modern, friendly, and easily readable interface.
- Use a clean, modern layout with ample whitespace to improve readability and reduce visual clutter.
- Employ simple, intuitive icons to represent different functions and sections within the admin panel.
